0522 Area Code

Lucknow STD Code & Phone Guide

Home Paisa Vasool

0522 is the STD (Subscriber Trunk Dialing) area code used for Lucknow, Uttar Pradesh, India.

This code is commonly used for landline telephone numbers in Lucknow region.

Where is 0522 Area Code Used?

0522 STD code is mainly used in:

  • Lucknow
  • Nearby Uttar Pradesh regions

How to Dial 0522 Numbers

  • Within India → Dial 0522 + phone number
  • From outside India → Dial +91 522 + phone number

Example

If a Lucknow landline number is 1234567, dial:

  • 0522-1234567 (within India)
  • +91-522-1234567 (international)

What is STD Code?

STD code identifies telephone regions in India for landline communication.

Lucknow uses 0522 STD code.
