011 Area Code

Delhi STD Code & Phone Guide

Home Paisa Vasool

011 is the STD (Subscriber Trunk Dialing) area code used for Delhi, India.

This area code is commonly used for landline phone numbers in Delhi and nearby NCR regions.

Where is 011 Area Code Used?

011 STD code is mainly used in:

  • New Delhi
  • Delhi NCR
  • Nearby urban regions

How to Dial 011 Numbers

  • Within India → Dial 011 + landline number
  • From outside India → Dial +91 11 + landline number

Example

If Delhi landline number is 12345678, dial:

  • 011-12345678 (within India)
  • +91-11-12345678 (international)

What is STD Code?

STD code identifies telephone regions in India for landline communication.

Related Area Codes

  • 022 Area Code – Mumbai

Frequently Asked Questions (FAQ)

Which city uses 011 area code?

Delhi uses 011 STD code.

Is 011 used for mobile numbers?

No, it is mainly used for landline numbers.

How to call Delhi from outside India?

Use +91 11 before the landline number.
